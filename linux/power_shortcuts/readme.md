# Linux Desktop Power Shortcuts

shortcuts that show up in the launch menu and require 0 clicks or waiting to reboot, shutdown, etc

this is the linux equivalent to https://github.com/chrishenn/lnks
installing and managing the lifecycle of these scripts can be automated with mise bootstrap:
- https://github.com/chrishenn/bootstrap/blob/e165d94369da70365bea590b89bc54e12608a8e8/home/.config/mise/conf.d/boot.aurora.toml#L111

---

scripted

```bash
./power_shortcuts.sh
```

manual

```bash
# edit the file opened by 'sudo visudo'
sudo visudo
```
